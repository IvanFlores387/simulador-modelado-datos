Manual del simulador

Guía de uso del Simulador de Modelado de Datos

Aprende cómo completar el Nivel 1, construir la entidad LIBRO, registrar atributos y validar correctamente tu modelo.

¿Qué es este simulador?

El Simulador de Modelado de Datos es una aplicación educativa diseñada para practicar la construcción de modelos de datos de forma visual. En cada nivel debes crear entidades, registrar atributos y validar si el modelo cumple con las reglas solicitadas.

Objetivo general

El objetivo del juego es aprender paso a paso cómo se construyen modelos de datos correctos, comenzando por entidades simples y avanzando hacia estructuras más completas con atributos, llaves primarias y relaciones.

Objetivo del Nivel 1: Biblioteca

En el Nivel 1 debes construir la entidad LIBRO. Esta entidad representa los libros que pueden registrarse en una biblioteca. Para completar el nivel, debes agregar los atributos necesarios para identificar el libro, registrar su título y guardar el nombre de su autor.

Pasos para completar el Nivel 1

  1. Presiona el botón Crear entidad LIBRO.
  2. Selecciona la entidad LIBRO en el lienzo de modelado.
  3. Agrega un atributo que represente el identificador del libro.
  4. Marca ese atributo como Llave primaria (PK).
  5. Agrega un atributo que represente el título del libro.
  6. Agrega un atributo que represente el autor del libro.
  7. Revisa la integridad del modelo.
  8. Presiona Validar modelo para comprobar si el nivel fue completado.

Atributos aceptados en el Nivel 1

Concepto Nombres aceptados Tipo de dato Requisito
Identificador del libro id, id_libro, codigo_libro, clave_libro INT Debe marcarse como PK
Título del libro titulo, nombre, nombre_libro, titulo_libro VARCHAR Debe tener longitud
Autor del libro autor, escritor, nombre_autor, autor_libro VARCHAR Debe tener longitud

Conceptos básicos

Entidad

Una entidad representa un objeto o elemento importante del sistema. En este nivel, la entidad principal es LIBRO.

Atributo

Un atributo es una característica de una entidad. Por ejemplo, un libro puede tener identificador, título y autor.

Llave primaria / PK

PK significa Primary Key o llave primaria. Es el atributo que identifica de forma única cada registro.

INT

INT es un tipo de dato usado para guardar números enteros.

VARCHAR

VARCHAR es un tipo de dato usado para guardar texto. Cuando uses VARCHAR, debes indicar una longitud válida, como 120 o 150.

Longitud

La longitud indica cuántos caracteres como máximo puede guardar un atributo de tipo VARCHAR.

Errores comunes

  • Crear la entidad pero no seleccionarla antes de agregar atributos.
  • Olvidar marcar el identificador como PK.
  • Usar VARCHAR sin indicar longitud.
  • Agregar nombres que no representan los conceptos esperados.
  • Agregar atributos repetidos.
  • Validar el modelo antes de completar los atributos requeridos.

¿Cómo corregir errores?

Si agregas un atributo incorrecto, puedes usar el botón Eliminar. Si quieres comenzar desde cero, puedes presionar Reiniciar nivel. Después de corregir el modelo, vuelve a presionar Validar modelo.

Integridad del modelo

La integridad del modelo indica el avance de construcción del nivel. Mientras más elementos correctos agregues, mayor será el porcentaje. Para completar el nivel, el modelo debe llegar al 100%.

Sonidos del simulador

El simulador utiliza sonidos para mejorar la experiencia. La pantalla de narrativa tiene música de inicio, el área de modelado tiene sonido de acción en bucle, los errores tienen un sonido de advertencia y el modelo correcto reproduce un sonido de logro.

Consejo final

Antes de validar, revisa que la entidad LIBRO exista, que tenga un identificador marcado como PK, y que los atributos de título y autor sean de tipo VARCHAR con longitud válida.
